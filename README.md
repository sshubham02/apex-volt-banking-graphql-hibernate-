# Apex Volt Banking API (Spring Boot + GraphQL + Hibernate)

This is a reference/sample application designed to help developers learn how to implement a GraphQL API over a PostgreSQL database using Spring Boot 3.x and Hibernate.

## 🚀 Technologies Used
- **Java 21**
- **Spring Boot 3**
- **Spring GraphQL**
- **Hibernate / Spring Data JPA**
- **PostgreSQL**

## 🛠️ How to Run Locally
1. Clone the repository.
2. Configure your database settings in `application.properties`.
3. Run `./mvnw spring-boot:run`.
4. Open `http://localhost:8080/graphiql` to test queries.
